# Sacred Timeline – Design

Style: calm Apple-like layout, PlayStation-style rounded buttons, Spotify-like poster rows. Dark only.

## Palette: Stark (red and gold)

| Token | Hex | Use |
|---|---|---|
| `--bg` | `#0E0F12` | Page background |
| `--surface` | `#181A1F` | Cards, poster placeholders |
| `--track` | `#23262D` | Empty part of progress bars |
| `--ink` | `#F2EFEA` | Main text |
| `--muted` | `#A7A39C` | Secondary text |
| `--accent` | `#E23636` | Marvel red: main button, progress fill |
| `--gold` | `#F5A524` | Iron Man gold: highlights (e.g. "Up next") |

Rules: flat colours, no gradients; one red action per screen; gold used sparingly.
